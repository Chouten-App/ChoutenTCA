# Chouten  
**Your All-in-One Content Hub**  

Chouten is an open-source multimedia consumption app, free to use.

---

## What’s Chouten?  

Chouten operates as a versatile modular system, adept at retrieving and presenting information from an array of third-party listing websites. It seamlessly interfaces with tracking services, facilitating the exchange of data to enhance user experiences and functionality.

## Get Started  
Ready to jump in? Here’s how to install Chouten:  

### TestFlight  
1. Open the TestFlight app on your iOS device.  
2. Use this link to join the beta: [TestFlight Link](#)  

### IPA File  
1. Grab the IPA file from [IPA Link](#).

## Contribute  
We’re all about community! Here’s how you can help make Chouten even better:  

1. Fork the repo on GitHub.  
2. Clone it to your machine **with submodules**:  
   ```bash
   git clone --recursive https://github.com/Chouten-App/ChoutenTCA.git
   ```  
3. Create a new branch for your feature or fix:  
   ```bash
   git checkout -b feature/your-cool-feature
   ```  
4. Make your changes and commit them:  
   ```bash
   git add .
   git commit -m "Your awesome commit message"
   ```  
5. Push your changes:  
   ```bash
   git push origin feature/your-cool-feature
   ```  
6. Open a pull request and let’s chat about it!
